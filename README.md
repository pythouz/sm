# Pulse MVP — الفيد الأساسي

## التشغيل
```bash
npm install
node demo.js
```

## اللي بيحصل
1. `identity.js` — أول مرة بيولّد مفتاح Nostr ويخزنه في `.pulse-identity.json` محلياً. المرات اللي بعدها بيستخدم نفس الهوية.
2. `feed.js` — بيتصل بـ 3 relays مجانية عامة (damus, primal, nos.lol)، ينشر منشور، ويشترك في فيدك.
3. `demo.js` — يشغل الاتنين ويطبع النتيجة.

## ملاحظة
جربته هنا وطلع `0/3 relay` لأن بيئة التنفيذ بتاعتي محجوب عليها الوصول لـ relays.damus.io وغيرها (سياسة شبكة داخلية). الكود سليم ومطابق للمواصفة — شغّله على جهازك أو سيرفرك ومفروض يطلع `3/3`.

## الخطوة الجاية
لو اشتغل عندك وطلعلك منشورك في الفيد، بعتلي النتيجة ونضيف اللايك والكومنت (NIP-25 / NIP-10).
